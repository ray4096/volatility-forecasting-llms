# Volatility Forecasting with FinBERT News Features

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ray4096/volatility-forecasting-llms/blob/main/notebook/Volatility_Forecasting_FinBERT.ipynb)

Code, results and thesis source for the master's thesis *Volatility Forecasting with Large Language Models*
(Md Tanjib Mahmud, Otto von Guericke University Magdeburg, supervisor: Jun.-Prof. Dr. Melina Ludolph).

**Question:** Do news features extracted with FinBERT improve one-day-ahead volatility forecasts of large US stocks
beyond GARCH(1,1), GJR-GARCH and EWMA benchmarks?

## Key results

* GJR-GARCH with Student-t errors is the most accurate baseline in both samples.
* News intensity (the number of relevant headlines) is strongly and positively related to next-day variance.
* Adding FinBERT news features (headline count and tone) to the GJR-GARCH-t baseline lowers the forecast loss slightly
  (QLIKE 2.185 → 2.170 in 2018 – May 2020, 1.997 → 1.986 in 2023). The improvement over a recalibrated
  baseline is significant at the 5% level in both samples (Diebold-Mariano p = 0.035 and p = 0.038).
* The gains are small, depend on the estimation method, last for one day only and reverse during the
  sharpest phase of the COVID-19 crash. Sentiment tone adds little beyond a simple count of headlines.

The full thesis is in [`thesis/Volatility_Forecasting_with_LLMs.pdf`](thesis/Volatility_Forecasting_with_LLMs.pdf).

## Data sources

* Prices: Yahoo Finance via `yfinance`.
* News headlines: FNSPID (Dong et al., 2024), Hugging Face dataset `Zihan1004/FNSPID`.
  The headlines are **not** redistributed here; Steps 2-3 of the notebook download and filter them.
* Constituents of the S&P 500: Wikipedia.

## How to reproduce

Run the notebook cell by cell in Google Colab (GPU runtime for Step 5). Intermediate files are written to Google Drive;
the large files (headlines, forecasts) are not included and are regenerated by the notebook.

Main packages: yfinance, pandas, numpy, scipy, statsmodels, arch, transformers (ProsusAI/finbert), torch, joblib, matplotlib.
To install them outside Colab: `pip install -r requirements.txt`.
