# Volatility Forecasting with FinBERT News Features

Code, results and thesis source for the master's thesis *Volatility Forecasting with Large Language Models*
(Md Tanjib Mahmud, Otto von Guericke University Magdeburg, supervisor: Jun.-Prof. Dr. Melina Ludolph).

**Question:** Do news features extracted with FinBERT improve one-day-ahead volatility forecasts of large US stocks
beyond GARCH(1,1), GJR-GARCH and EWMA benchmarks?

## Contents

| Path | Description |
|---|---|
| `notebook/Volatility_Forecasting_FinBERT.ipynb` | Full pipeline, Steps 1-10 (run in Google Colab), with all outputs |
| `data/sample_main.csv`, `data/sample_robust.csv` | The 47 and 44 selected stocks |
| `data/descriptive_stats_main.csv` | Descriptive statistics of returns (main sample) |
| `data/results_news_models.csv` | Out-of-sample accuracy and Diebold-Mariano tests, all models |

| `data/features_daily.csv.gz` | Daily news features per stock |

| `thesis/` | LaTeX source (`main.tex`, `literature.tex`, `references.bib`) and the compiled PDF |

## Data sources

* Prices: Yahoo Finance via `yfinance`.
* News headlines: FNSPID (Dong et al., 2024), Hugging Face dataset `Zihan1004/FNSPID`.
  The headlines are **not** redistributed here; Steps 2-3 of the notebook download and filter them.
* Constituents of the S&P 500: Wikipedia.

## How to reproduce

Run the notebook cell by cell in Google Colab (GPU runtime for Step 5). Intermediate files are written to Google Drive;
the large files (headlines, forecasts) are not included and are regenerated by the notebook.

Main packages: yfinance, pandas, numpy, scipy, statsmodels, arch, transformers (ProsusAI/finbert), torch, joblib, matplotlib.
