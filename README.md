# Volatility Forecasting with Large Language Models

## About the Project

This project is based on my master's thesis at Otto von Guericke University Magdeburg, Germany.

It investigates financial volatility forecasting. The project examines traditional forecasting models and the potential use of Large Language Models (LLMs) to analyse financial news.

## Research Objectives

- Study financial volatility forecasting.
- Work with traditional models such as GARCH and EWMA.
- Explore the use of LLMs to extract information from financial news.
- Compare forecasting results using quantitative evaluation metrics.

## Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Financial time-series analysis
- Large Language Models

## Repository Contents

- `notebooks/` — Jupyter Notebooks containing the analysis and experiments.
